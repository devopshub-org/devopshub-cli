# devopshub-cli Roadmap

This document outlines the vision and upcoming milestones for `devopshub-cli`.

## 📌 Vision
To provide a unified, developer-friendly CLI interface for managing modern DevOps pipelines, cloud resources, and operational tooling.

---

## 🎯 Release Milestones

### v0.1.0
Initial release of DevOpsHub CLI.

- [ ] CLI
- [ ] Docker cheatsheet
- [ ] Kubernetes cheatsheet
- [ ] Linux cheatsheet
- [ ] Version command

### Phase 2: Cloud & Kubernetes Integration (v0.2.0)
- [ ] Cluster inspection & diagnostic commands
- [ ] Cloud provider credential helper
- [ ] Resource usage & cost estimation snippets

### Phase 3: Automation & CI/CD Pipeline Support (v0.3.0)
- [ ] GitHub Actions / GitLab CI runner helpers
- [ ] Infrastructure drift detection
- [ ] Interactive terminal UI (TUI) for cluster management

---

> Note: Features and timeline are subject to change based on community feedback.
